# 네이버 블로그 SEO 가이드

> 작성일: 2026-10-17
> **먼저 알아둘 점:** 네이버는 글자 수, 사진 장수, 키워드 횟수, 태그 개수 같은 **수치 기준을 공개한 적이 없습니다.**
> 아래 수치 대부분은 블로그 마케팅 업체와 개인 블로거의 경험칙입니다. 그래서 항목마다 근거 등급을 붙였습니다.
>
> - 🟢 **공식**: 네이버 공지·검색 가이드에 근거가 있음 (방향성만 있고 수치는 없음)
> - 🟡 **통설**: 여러 업계 자료가 비슷하게 말하지만 공식 근거는 없음 (참고용 기본값)
> - 🔴 **미확인**: 이번 조사에서 근거를 찾지 못함 (내 제안이거나 직접 테스트가 필요)

---

## 1. 제목 작성 규칙

| 항목 | 규칙 | 등급 |
|---|---|---|
| 글자 수 | **25~35자** 안팎을 기본값으로 삼기. 모바일 검색결과에서 약 35자 근처에서 잘린다는 설명이 근거. 출처별로 15~25자, 28~42자, 30~40자로 제각각 | 🟡 |
| 핵심 키워드 위치 | **제목 앞쪽**에 배치 (거의 모든 자료가 일치) | 🟡 |
| 키워드 횟수 | 핵심 키워드는 **1회**, 연관 키워드 포함해 2~3개까지. 3개를 넘으면 핵심 메시지가 흐려짐 | 🟡 |
| 구성 공식 | `핵심 키워드 + 대상/상황/고민 + 해결 방향` (예: 지역 + 서비스 + 후킹 문구) | 🟡 |
| 형태 | 검색자 의도를 반영한 질문형·구어체, 구체적 숫자("5가지") 활용 | 🟡 |
| 넓은 키워드 | "홍대 카페", "일본 여행" 같은 대표 키워드만 쓰면 경쟁에 밀림. 세부 주제로 좁히기 | 🟡 |

### 피해야 할 것
- **키워드 나열**: "맛집 맛집추천 강남맛집" 형태 (인위적 반복은 순위에서 불리) 🟢
- **특수문자·기호 남용**: 많은 자료가 비권장. 쓰더라도 최소한으로 🟡
- **같은 제목 키워드를 여러 글에 반복**: 누락될 수 있으니 표현을 바꾸기 🟡
- **광고성 어투**: 제품 홍보만 드러나는 제목 🟡
- **본문과 무관한 키워드, 낚시성 제목**: 문서 의도와 검색 의도 불일치 🟢
- **"최고", "무조건" 같은 특정 금칙어**: 금칙어로 확인된 목록은 **없음**. 금칙어 리스트보다 내용의 정확성이 중요하다는 의견이 우세 🔴

## 2. 본문 구조

| 항목 | 규칙 | 등급 |
|---|---|---|
| 글 길이 | 1,500자 이상이 통설이지만, 공식 기준 없음. 분량보다 **정보 배치**가 중요 | 🟡 |
| 첫 문단 | 핵심 내용을 먼저 요약하고, 키워드를 첫 100자 안에 자연스럽게 포함 | 🟡 |
| 소제목 | 소제목·문단·표·목록으로 훑어보기 쉽게 구성. 소제목에 연관 키워드 포함. 질문형 소제목이 AI 요약 검색 환경에서 유리하다는 주장 | 🟢 구조 활용 권장 / 🟡 질문형 |
| 강조 | 굵은 글씨, 목록으로 핵심 강조. 긴 글은 목차 | 🟡 |
| **도입-본론-결론 비율** | **근거 자료를 찾지 못함.** 아래는 내 제안(검증 필요) | 🔴 |

### 비율 제안 (🔴 근거 없음, 테스트용 기본값)
- 도입 약 10~15% : 독자의 고민 제시 + 이 글에서 얻을 것 요약
- 본론 약 70~75% : 소제목 3~5개로 나눠 경험·사례·구체 정보 전개
- 결론 약 10~15% : 핵심 요약 + 다음 행동 안내 (연관 글 링크 등)

### 본문 작성 원칙
- 글자 수보다 **검색 의도에 맞는 내용이 실제로 있는지**가 핵심 (D.I.A.+) 🟢
- 이미지 안에만 텍스트를 넣지 말 것. 검색 봇이 못 읽을 수 있음 🟡

## 3. 키워드 밀도와 배치

| 항목 | 규칙 | 등급 |
|---|---|---|
| 적정 횟수 | 공식 기준 없음. 통설은 핵심 키워드 **3~5회**, 본문 길이에 따라 조정 | 🟡 |
| 밀도 | 1.5~3%라는 수치가 돌지만 근거 약함. 밀도보다 **자연스러운 문맥** 우선 | 🔴 |
| 상한 | 5~10회 이상 같은 키워드 반복은 감점 위험 | 🟡 |
| 배치 위치 | 제목 1회 → 첫 100자 → 소제목 → 본문 곳곳 → 결론 | 🟡 |
| 연관 키워드 | 동의어·세부 키워드를 섞어 쓰기 | 🟡 |

**실전 팁:** 키워드를 의식적으로 세지 말고, 쓰고 난 뒤 소리 내어 읽었을 때 어색한 반복이 없으면 통과로 봅니다.

## 4. 이미지

| 항목 | 규칙 | 등급 |
|---|---|---|
| 장수 | 공식 기준 없음. 통설은 **5~10장**, 글 전체에 분산 배치 | 🟡 |
| 원본성 | **직접 촬영한 원본 사진** 권장. D.I.A.는 이미지 원본 여부를 판별하는 기술 보유 | 🟢 |
| 타인 이미지 | 무단 재업로드는 감점 위험 | 🟡 |
| 대표 이미지 지정 | 지정하지 않으면 본문 **최상단 이미지**가 썸네일. 원하는 사진은 좌측 상단 **[대표]** 버튼으로 지정 | 🟢 |
| 대표 이미지 비율 | PC 3:2, 모바일 1:1 자동 적용, 공유 시 16:9. **16:9로 제작하되 중요한 내용은 중앙 1:1 안에** 두기 | 🟡 |
| 대표 이미지 픽셀 크기 | 네이버 블로그 기준 수치를 찾지 못함 | 🔴 |
| alt 텍스트 | 네이버 블로그는 일반 웹처럼 alt를 넣는 기능을 **별도로 제공하지 않는다**는 설명이 있음. 사진 설명(캡션)을 본문 텍스트로 보완하는 편이 안전 | 🔴 |
| 용량 | 로딩 속도를 위해 적당히 압축 | 🟡 |

## 5. 해시태그

**이번 조사에서 해시태그 개수와 상위노출의 관계를 확인한 근거는 없습니다.** (🔴)

- 일부 자료는 글과 관련된 **5~10개**를 권하지만, 근거는 제시되지 않았습니다. 🟡
- 태그는 글의 주제를 알리는 메타데이터 역할을 합니다. 핵심 키워드 + 연관 키워드 조합이 무난합니다.
- 본문과 무관한 인기 태그 나열은 키워드 어뷰징으로 보일 수 있으니 피하세요.
- 태그 효과는 직접 측정을 권합니다. 같은 주제 글에서 태그 수만 다르게 해 노출 차이를 기록하세요.

## 6. C-Rank · D.I.A.+ 가 좋아하는 패턴

### 역할 구분 🟢
- **C-Rank**: 출처(블로그)의 신뢰도. 블로그 전체의 주제 분포로 **집중도**를 계산
- **D.I.A.+**: 개별 문서의 정보성과 검색 의도 적합성. 문서 구조·본문 텍스트·이미지 정보에서 패턴 추출
- 점수가 높을수록 유리하지만 **항상 상위노출이 보장되는 출처는 없다**고 네이버가 밝힘

### 선호 패턴

| 패턴 | 내용 | 등급 |
|---|---|---|
| 주제 집중 | 블로그 글 대부분을 핵심 주제 중심으로 채우기 | 🟢 |
| 경험 정보 | 직접 겪은 사례, 실패 경험, 상세 후기 | 🟢 |
| 정보의 충실성 | 가격, 소요 시간 등 독자가 궁금해할 구체 정보 | 🟢 |
| 독창성 | 복사·짜깁기가 아닌 자기 글, 원본 사진 | 🟢 |
| 적시성 | 최신 정보 | 🟢 |
| 검색 의도 부합 | 질의 의도에 맞는 답이 실제로 들어 있는 글 | 🟢 |
| 광고 표시 | 협찬·대가성 여부를 명시 (미표시는 제재 대상) | 🟢 |
| 꾸준한 활동 | 최근 30일 활동성이 중요하다는 주장 | 🟡 |
| 체류시간 | 긴 체류, 낮은 이탈이 긍정 신호라는 주장 | 🟡 |

## 7. 어뷰징으로 판정되는 것들 (피해야 할 것)

> 네이버는 "저품질 블로그"라는 용어를 공식 정의하지 않았습니다. 아래 중 🟢만 공식 근거가 있습니다.

| 행위 | 설명 | 등급 |
|---|---|---|
| 복사·짜깁기 | 타인 글·뉴스·보도자료 복사 | 🟢 |
| 생성형 AI 대량 생성 | 비독창적 글을 대량으로 찍어내기 | 🟢 |
| 키워드 인위적 반복 | "맛집 맛집 맛집" 식 반복 | 🟢 |
| 대가성 미표시 | 협찬·광고 표기 누락 | 🟢 |
| 정확히 일정한 발행 간격 | 기계적 패턴은 어뷰징으로 오판될 수 있음 | 🟢 |
| 댓글·공감·스크랩 조작 | 프로그램·품앗이로 인위적 반응 만들기 | 🟡 |
| 대량 발행 | 하루 10개 이상 발행 | 🟡 |
| 초단문 글 반복 | 300자 미만 글을 여러 개 발행 | 🟡 |
| 광고성 글 과다 | 전체 글의 30%를 넘는 광고 포스팅 | 🟡 |
| 상업성 외부 링크 남발 | 과도한 외부 링크 | 🟡 |
| 금지 주제 | 성인, 도박, 불법 금융 등 | 🟡 |
| 타인 사진 재업로드 | 출처 불명 이미지 | 🟡 |

**참고:** "하루 1~3개 발행", "매일 포스팅해야 한다", "1,500자·사진 5장이 기준" 같은 말은 공식 기준이 아닌 **소문**으로 분류됩니다.

## 실전 체크리스트

- [ ] 제목 25~35자, 핵심 키워드는 앞쪽 1회
- [ ] 제목에 키워드 나열·과한 특수문자 없음
- [ ] 첫 문단에 핵심 요약과 키워드
- [ ] 소제목으로 구조화 (질문형 활용)
- [ ] 직접 겪은 경험, 가격·시간 등 구체 정보 포함
- [ ] 직접 찍은 사진 5장 안팎, 대표 이미지 지정(16:9, 중앙 1:1 안전영역)
- [ ] 키워드는 자연스럽게, 어색한 반복 없음
- [ ] 태그는 글과 관련된 것만
- [ ] 협찬이면 대가성 표시
- [ ] 블로그 주제와 글 주제의 일관성 유지

---

## 근거 한계와 후속 확인 필요 항목

- 도입-본론-결론 비율, 해시태그 개수 효과, 대표 이미지 픽셀 크기, alt 텍스트 처리는 **근거를 찾지 못했습니다.**
- 대부분의 출처가 마케팅 업체·개인 블로그라 수치가 서로 다릅니다.
- 정확한 기준은 네이버 서치어드바이저와 블로그 공식 공지에서 확인하세요.
- 가장 믿을 만한 방법은 **내 블로그에서 직접 A/B 테스트**하고 결과를 기록하는 것입니다.
