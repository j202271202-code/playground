# 블로그 이미지 제작 가이드

> **이 문서의 목적**: image-maker 에이전트가 이 파일 하나만 읽고도, 블로그 글의 대표 이미지와 본문 삽입 이미지를
> 일관된 규격으로 만들 수 있게 한다. 글의 내용·문체는 다루지 않는다. 이미지 규격, 레이아웃, 제작 방식만 다룬다.

---

## 1. 대표 이미지 규격

| 항목 | 규칙 |
|---|---|
| 크기 | 가로 1080px × 세로 1080px (1:1 정사각형) |
| 배경 | 어두운 블루-퍼플 그라데이션: `#1a1a2e` → `#16213e` |
| 메인 텍스트 | 글 제목. 큰 글씨, 흰색 |
| 보조 텍스트 | 카테고리 또는 부제. 작은 글씨, 연한 회색 |
| 텍스트 정렬 | 메인·보조 텍스트 모두 가로·세로 중앙 정렬 |
| 폰트 | Pretendard, 없으면 시스템 기본 한글 폰트로 대체 |
| 액센트 | 우측 하단 또는 좌상단에 작은 포인트 요소(도형, 코드 심볼, 단순 아이콘) 하나 |

> 배경 그라데이션 두 번째 색상값은 `#16213e`를 쓴다. (전달받은 원문에는 `#162113e`로 적혀 있었는데, 7자리 값이라 유효한 HEX 코드가 아니다. 많이 쓰이는 다크 네이비 조합 `#1a1a2e → #16213e`와 사실상 동일한 값으로 보여 이 값으로 바로잡았다. 다른 색을 의도했다면 알려 달라.)

### 레이아웃 메모
- 제목이 길면 2~3줄로 줄바꿈하되, 세로 중앙 정렬 기준은 유지한다.
- 메인 텍스트와 보조 텍스트 사이에는 여백을 둬서 둘이 뭉치지 않게 한다.
- 액센트 요소는 제목을 가리지 않는 위치(우측 하단 또는 좌상단 모서리)에만 둔다.

---

## 2. 본문 삽입 이미지 — 네 가지 유형

글쓴이가 `[IMAGE: 설명]`으로 남긴 자리마다, 그 설명 내용에 맞춰 아래 네 유형 중 하나를 고른다.

| 유형 | 언제 쓰나 |
|---|---|
| ① 비교 표 | 제품·방법·옵션을 나란히 비교할 때 |
| ② 단계별 다이어그램 | 절차나 순서를 보여줄 때 (워크플로우, 단계 흐름 등) |
| ③ 핵심 포인트 카드 | 3~5개의 요점을 정리할 때 |
| ④ 인용/강조 박스 | 중요한 한 문장을 강조할 때 |

`[IMAGE: 설명]` 문구만으로 유형이 애매하면, 바로 앞뒤 문단의 내용(비교하고 있는지, 순서를 설명하는지, 요점을 나열하는지, 한 문장을 강조하는지)을 보고 판단한다.

---

## 3. 공통 규칙

- **제작 방식**: HTML + CSS로 디자인하고, Python에서 Playwright를 실행해 PNG로 캡처한다. (다른 방식으로 임의 대체하지 않는다.)
- **배경 톤**: 본문 전체 분위기와 어울리게 맞춘다. 대표 이미지의 어두운 블루-퍼플 계열과 톤을 맞추거나, 최소한 과도하게 튀는 색은 피한다.
- **텍스트 양**: 최대한 짧게 쓴다. 이미지는 글을 대신하는 것이 아니라 보조하는 역할이다. 문장을 통째로 옮기지 않고 핵심 단어·짧은 구로 압축한다.
- **코드 블록 스타일 활용**: 필요하면 모노스페이스 폰트 + 어두운 배경의 "코드 블록"처럼 보이는 디자인을 포인트로 쓸 수 있다. (예: 터미널 창처럼 보이는 카드, 콘솔 프롬프트 느낌의 텍스트)

---

## 4. 작업 절차 (image-maker 에이전트용)

1. 대표 이미지가 필요하면 "1. 대표 이미지 규격"을 그대로 따라 HTML+CSS를 작성한다. 글 제목과 부제(카테고리)를 받아 텍스트를 채운다.
2. 본문에 `[IMAGE: 설명]`이 있으면, 그 설명을 읽고 "2. 본문 삽입 이미지 — 네 가지 유형" 중 가장 맞는 유형을 고른다.
3. 선택한 유형에 맞는 HTML+CSS를 작성한다. 텍스트는 짧게, 배경 톤은 본문과 어울리게 맞춘다.
4. Python + Playwright로 HTML을 렌더링해 PNG로 캡처한다.
5. 대표 이미지는 1080×1080px, 본문 삽입 이미지는 내용에 맞는 적절한 크기로 저장한다.

---

## 5. 체크리스트

- [ ] 대표 이미지가 1080×1080px, 지정된 그라데이션 배경을 쓴다.
- [ ] 대표 이미지의 메인/보조 텍스트가 가로·세로 중앙 정렬되어 있다.
- [ ] 본문 삽입 이미지가 네 가지 유형 중 내용에 맞는 것으로 골라졌다.
- [ ] 모든 이미지의 텍스트가 짧고, 문장을 그대로 옮기지 않았다.
- [ ] 배경 톤이 본문 분위기와 어울린다.
- [ ] HTML+CSS로 만들고 Playwright로 PNG 캡처했다. (다른 방식을 쓰지 않았다.)
